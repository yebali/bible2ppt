# 성경 자막 PPT 만들기

장·절을 입력하면 예배 생중계용 하단 자막 PPT(크로마키 녹색 배경)를 만들어 줍니다.

## 실행 (개발)

```
python -m venv .venv
.venv/bin/pip install -r requirements.txt      # 윈도우: .venv\Scripts\pip
.venv/bin/python app.py
```

## 윈도우용 exe 만들기 (윈도우 PC에서)

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
.venv\Scripts\pyinstaller --noconsole --name 성경자막 app.py
xcopy /E /I bibles dist\성경자막\bibles
```

`dist\성경자막` 폴더 통째로 교회 PC에 복사하고 `성경자막.exe`를 실행하면 됩니다.
`bibles` 폴더는 exe 옆에 두어야 합니다. `template.pptx`는 처음 실행할 때 그 PC의 글꼴에 맞춰 자동으로 만들어지고,
설정은 같은 폴더의 `settings.json`에 저장됩니다. (바탕화면처럼 쓰기 가능한 폴더에 두세요)

## 입력 예

`창1:1-5` · `창세기 1:1-5` · `요3:16` · `시23` · `창1:30-2:3` · `왕상19:1-5, 약5:17`

- 책 이름은 앞 글자만 쳐도 자동완성 목록이 뜹니다 (↑↓로 고르고 Enter/Tab)
- 입력칸이 비었을 때 ↓를 누르면 최근 입력 목록
- Enter 또는 "PPT 만들기": 파일 저장 후 열기 (치다가 멈추면 미리보기는 자동으로 나옴)
- PageUp/PageDown: 미리보기 슬라이드 넘기기

## 모양 바꾸기 (template.pptx)

설정 → "PowerPoint로 열기"로 템플릿을 고칩니다. 첫 슬라이드의 글상자 하나가 자막 띠입니다.

- 글상자 채우기 = 띠 색·투명도, `{본문}` 글자의 서식 = 본문 서식
- `{본문}` 글자는 지우지 마세요
- 띠(글상자)의 위치와 크기는 모든 슬라이드에서 템플릿 그대로입니다. 글자의 세로 위치는 글상자의 "텍스트 맞춤"(위쪽/가운데/아래쪽)을 따릅니다
- 띠에 들어가는 줄 수보다 설정의 최대 줄 수가 크면 띠에 맞춰 나누고 화면에 알려 줍니다
- 배경색, 로고 그림, 다른 글상자는 모든 슬라이드에 그대로 복제됩니다
- 템플릿 파일을 지우면 기본 템플릿이 다시 만들어집니다

맑은 고딕이 아닌 글꼴로 바꾸면 `ppt.py`의 `FONT_FILES`에 글꼴 파일 이름을 추가해야 줄 나눔이 정확합니다.

## 성경 데이터 (bibles/)

- `python -m util.crawl` (프로젝트 폴더에서) : 대한성서공회 사이트에서 개역개정·개역한글·새번역·표준새번역·공동번역·공동번역개정판·CEV
- 파일 이름은 영문 코드입니다 (맥에서 만든 한글 파일 이름은 윈도우에서 깨질 수 있어서):
  `GAE` 개역개정, `HAN` 개역한글, `SAE` 표준새번역, `SAENEW` 새번역, `COG` 공동번역, `COGNEW` 공동번역개정판, `CEV`
- 같은 형식(`{"책코드": {"장": {"절": "본문"}}}`)의 JSON을 넣으면 번역본 목록에 자동으로 나타납니다.
  위 코드가 아닌 파일은 파일 이름 그대로 목록에 보입니다 (예: `WOORI.json` → WOORI)
